# 📝 TodoApp

**TodoApp** es una aplicación móvil para la **gestión de tareas diarias**, diseñada para ayudarte a organizar, priorizar y completar tus pendientes de forma eficiente.

---

## 📱 Funcionalidades

* ✅ **Listado de tareas**: visualiza tareas pendientes y completadas en una interfaz clara y amigable.
* ➕ **Agregar tareas**: crea nuevas tareas con facilidad.
* 🔍 **Filtros**: navega fácilmente entre tareas usando filtros por estado, categoría o prioridad.
* 🗂️ **Categorías y prioridades**: organiza tus tareas según su tipo e importancia.
* 🙌 **Sección de créditos**: incluye reconocimiento al desarrollador y la institución que respalda el proyecto.

---

## 📌 Objetivo

Facilitar el día a día de los usuarios mediante una app intuitiva y funcional para el manejo de tareas personales o profesionales.
